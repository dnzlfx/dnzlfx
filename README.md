## About

I'm Christian, a full-stack developer. Most of my time goes into local AI and automation, almost always on Linux with Docker. I care about software that runs on your own machines and that you can read end to end.

Lately I've been building agents with memory, vision and voice, plus local model inference and homelab automation.

## Projects

- [Vyn — Voice Your Needs](https://github.com/dnzlfx/Vyn): local-first autonomous agent with inference through Ollama, persistent memory, web search, a code sandbox, vision and homelab administration over SSH.
- [Samantha](https://github.com/dnzlfx/Samantha): multimodal assistant with voice, vision, screen monitoring and intent detection. I use it as a visual copilot for tasks, diagnostics and debugging.
- [Local AI Assistant](https://github.com/dnzlfx/Local_AI_Assistant): configurable assistant built on local models, with contextual web search, hot model switching and automatic session saving.
- [FoxTube](https://github.com/dnzlfx/foxtube): private, self-hosted YouTube frontend on Invidious, with its own interface, local recommendations, Shorts and containerized deployment. MIT licensed.
- [ProyectoPrograWeb](https://github.com/dnzlfx/ProyectoPrograWeb): static multi-page site (catalog, accessories, blog and contact) published with GitHub Pages.
- [Impact Forge — AppealForge](https://github.com/dnzlfx/Impact_Forge-AppealForge): AI-assisted clinical appeals system that overturns medical insurance denials with clinical guideline retrieval (RAG), verified drafting and independent audit. Team project (Impact Forge Hackathon 2026).
